02Work

This portfolio

HTMLCSSJavaScriptNo frameworkNo build step

Seven static pages with no framework, no bundler and no CSS library. The layout system is hand-written CSS grid on a custom-property token set; the icons are an authored inline SVG sprite at one stroke weight; the type is a self-hosted Archivo variable font subset into latin and latin-ext ranges. The single interaction is a light band that reads scroll and pointer position and lights the label stock it crosses.

Accessibility is built in rather than retrofitted: visible focus rings on every control, a skip link, honest landmarks and heading order, labelled form fields, AA contrast, and a reduced-motion path that removes the motion instead of shortening it.
