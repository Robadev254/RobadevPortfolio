About

I build product-ready interfaces and dependable systems for teams that need clarity, speed, and clean execution.

00Subject

Anthony Mwongela

Software EngineerNairobi, KenyaFull-stack web

I came to engineering through a four-year BSc in Software Development at KCA University, then spent twelve months in the ALX Africa Software Engineering programme, where most of the work was Linux, shell and system engineering done task by task rather than in one sitting. The combination is deliberate: I can build the interface, the service behind it, and the environment it runs in.

My day-to-day preference is frontend and full-stack web work. I like problems where the constraint is clarity — making a dense screen legible, making a form honest about what it will do, making a layout survive a 320px phone without a second codebase. I build with the same standard I would expect from a founder-led product team: lean, readable, testable, and designed for real users rather than for the demo alone.

I am early in my career and I would rather say so than imply otherwise. What I can show you is real: repositories you can read line by line, grades as they were awarded, and an explicit record of what has not happened yet.

How I work

Read the existing code before adding to it. Keep the smallest thing that actually solves the problem. Name things so the next person does not have to ask. Test the edges — empty states, bad input, slow networks — because those are where real users live. Write the accessibility in from the start rather than auditing it in afterwards.
